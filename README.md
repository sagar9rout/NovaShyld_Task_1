# NovaShyld Task 1 – Cybersecurity Fundamentals

## Overview

This repository contains the work completed for Task 1 of the Cybersecurity Analyst Internship.

The goal is not only to define security terms, but to understand how the pieces connect when a real organization is compromised.

## Internship Requirements Covered

- Cybersecurity fundamentals notes
- CIA Triad
- Common attack vectors and social engineering
- Threat modeling basics
- MITRE ATT&CK basics
- Real-world breach case-study analysis
- Cybersecurity awareness report (PDF)

## Case Study

**Equifax 2017 Data Breach**

The case study examines how an unpatched Apache Struts vulnerability, weak security controls, and insufficient network protections contributed to a major exposure of sensitive personal information.

## What I Practiced

During this task, I focused on connecting security concepts rather than
memorizing definitions.

I practiced:

- identifying assets, threats, vulnerabilities and risks
- applying the CIA Triad to a real incident
- breaking a breach into an attack chain
- using MITRE ATT&CK to describe attacker behavior
- separating confirmed evidence from assumptions
- thinking about the same incident from both attacker and defender perspectives

## Approach

For each topic, the learning process is:

**Understand → Connect the concept to a real incident → Think like an attacker → Think like a defender → Document the lesson**

## Ethics

All practical security testing associated with this internship must be performed only against systems that are explicitly authorized and isolated for testing.
